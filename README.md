# RealForge downloads

**[Download RealForge for Mac](https://github.com/nicholaslasagna/RealForge-releases/releases/latest/download/RealForge-macOS-AppleSilicon.dmg)** · Apple silicon (M1 or newer), macOS 12 or later

Or use the download page: https://nicholaslasagna.github.io/RealForge-releases/

## Install

1. Open the downloaded `.dmg`.
2. Drag **RealForge** into **Applications**.
3. Open RealForge from Applications.

Updates arrive inside the app; it asks before installing one. Updating keeps your settings and history.

Every release is signed with a Developer ID and notarized by Apple. `SHA256SUMS.txt` on each release lets you verify your download.

This repository only publishes releases. The app's source code is private.
