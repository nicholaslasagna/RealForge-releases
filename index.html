How to install

A minute or two, start to finish.

macOS
  1. Open the downloaded .dmg file.
  2. Drag RealForge into the Applications folder.
  3. Open it from Applications or Launchpad.
Windows
  1. Open RealForge-Windows-Setup.exe from your Downloads.
  2. If Windows says it protected your PC, choose More info, then Run anyway.
  3. Follow the installer. It takes under a minute.
  4. Open RealForge from the Start menu.
Linux
  1. AppImage: make it runnable with chmod +x RealForge-Linux.AppImage, then open it.
  2. Debian or Ubuntu: run sudo apt install ./RealForge-Linux.deb.
